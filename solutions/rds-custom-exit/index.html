AWS is retiring Amazon RDS Custom for Oracle. After March 31, 2027 you can no longer access the RDS Custom console or its resources. We give you a fixed-price exit plan, then move every database with a rehearsed cut-over and a way back.

The challenge

Sound familiar?

  • You run Oracle on RDS Custom and the March 31, 2027 date is already in your risk register.

FAQ

Questions about this solution

Straight answers on scope, price and how we work. Anything else, ask us.

What happens to RDS Custom for Oracle after March 31, 2027?

AWS states that after March 31, 2027 you will no longer be able to access the RDS Custom for Oracle console or RDS Custom for Oracle resources. AWS recommends migrating to self-managed Oracle on Amazon EC2.

Which migration method do you use?

Usually Oracle Data Guard for production, because it allows a switchover in seconds to minutes and keeps the old primary as a standby for fallback. RMAN active duplication suits planned cut-overs and non-production. Both are documented by AWS for this exit.

Do we have to go to EC2?

No. EC2 is the path AWS documents, but Amazon RDS for Oracle or Oracle Database@AWS can fit better depending on edition, features and how much operations work you want to keep. The exit plan compares them for each database.

Is the exit plan fee credited?

Yes. The exit plan fee is deducted from the fixed price of the migration if you go ahead.

How much downtime should we expect?

With Data Guard, the switchover itself is typically seconds to minutes. We rehearse it first so you know the real number before the production cut-over.
