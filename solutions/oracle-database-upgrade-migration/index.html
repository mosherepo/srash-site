FAQ

Questions about this solution

Straight answers on scope, price and how we work. Anything else, ask us.

When does Oracle Database 19c support end?

Oracle's Lifetime Support Policy lists Premier Support for 19c to December 2029 and Extended Support to December 2032.

Can we upgrade 19c straight to 26ai?

Yes. Oracle supports direct upgrades to 26ai from 19c and 21c. Earlier releases need an intermediate upgrade first.

Does 26ai still support non-CDB databases?

No. Releases after 19c use the multitenant architecture only, so a non-CDB is converted to a pluggable database as part of the upgrade.

Should we move off Oracle?

Sometimes. We recommend PostgreSQL only where the PL/SQL volume, features in use and licence savings justify it, and we put the reasoning in writing.
