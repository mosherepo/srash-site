Database Upgrades & End-of-Support Programs

Every engine has a clock. RDS and Cloud SQL now bill for extended support on old PostgreSQL and MySQL versions, SQL Server 2017 support ends in October 2027 and MongoDB 7.0 in August 2027. We plan, rehearse and run the upgrades on a fixed fee.

Sound familiar?

  • Your AWS bill now carries RDS Extended Support charges for MySQL 8.0 or PostgreSQL 13, and PostgreSQL 14 joins them on February 28, 2027.
  • You still run SQL Server 2016, which left extended support in July 2026, or SQL Server 2017, which follows on October 13, 2027.
  • MongoDB 6.0 is already past end of life, 7.0 ends on August 31, 2027, and nobody has tested the drivers against 8.0.
  • Cassandra 3.x or Aerospike 7.x clusters are out of support and the upgrade path cannot skip versions.

  • Inventory of versions, support dates and extended-support cost
  • Upgrade path and runbook per database
  • Compatibility test results
  • Rehearsal timings and rollback plan
  • Post-upgrade cost and performance report

    Extended-support charges removed, instance classes right-sized and reserved capacity reviewed after the upgrade.

Questions about this service

Straight answers on scope, fees and how we work. Anything else, ask us.

Ask a question

What does RDS Extended Support cost us?

AWS charges per vCPU-hour for each instance running a major version past its end of standard support. The charge rises in the third year. The readiness review lists the exact instances and the monthly amount from your own bill.

Can we skip versions?

Often, but not always. PostgreSQL can jump several majors with pg_upgrade or logical replication; Cassandra and MongoDB need one major at a time. The review sets the shortest supported path for each engine.

How much downtime should we expect?

Blue/green or replication-based upgrades usually need a switchover of seconds to minutes. In-place upgrades take longer. We measure it in rehearsal before production.

Is the review fee credited?

Yes. The full fee is deducted from the fixed fee of the upgrade program if you go ahead.
