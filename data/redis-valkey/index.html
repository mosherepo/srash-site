FAQ

Questions about this service

Straight answers on scope, price and how we work. Anything else, ask us.

Is Redis still open source?

Redis 7.4 moved to RSALv2 or SSPLv1. Redis 8 added AGPLv3 as a third option, which is OSI-approved but carries network copyleft obligations. Valkey, forked from Redis 7.2.4, remains BSD-licensed. Have counsel confirm how this applies to you.

Can Valkey read our Redis data?

Valkey reads the data files of Redis OSS 7.2 and earlier. Data from Redis 7.4 and later needs a logical migration rather than a file copy.

What happens if we ignore the Azure Cache for Redis retirement?

Microsoft says remaining Enterprise caches are migrated or disabled from April 1, 2027, and Basic, Standard and Premium caches are disabled from October 1, 2028.

Is the review fee credited?

Yes, in full, toward the migration if you go ahead.
