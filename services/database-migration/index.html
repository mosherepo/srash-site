Questions about database migration

How long does an Oracle to PostgreSQL migration take?

A single application schema typically takes 6 to 16 weeks end to end, depending on PL/SQL volume and data size. The free assessment gives you a scoped estimate and a fixed price before you commit.

What happens to RDS Custom for Oracle after March 31, 2027?

AWS has announced that after March 31, 2027 you can no longer access RDS Custom for Oracle resources, including instances and snapshots. AWS recommends moving to Oracle on Amazon EC2; RDS for Oracle and Oracle Database@AWS are also options depending on edition and features.

Can you keep downtime to a minimum?

Yes. We use Data Guard, GoldenGate or AWS DMS change data capture so the final cut-over is minutes, and we rehearse it before the real one.
