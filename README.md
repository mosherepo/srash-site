# SRASH website demo

Public preview of the rebuilt [srash.io](https://srash.io) site, hosted at https://mosherepo.github.io/srash-site/.

This copy has `<meta name="robots" content="noindex">` on every page and a `robots.txt` that disallows all crawlers, so it does not compete with the production domain. Canonical URLs still point at srash.io.
